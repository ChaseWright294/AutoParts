# AutoParts

Group project for CSCE 4350 Fundamentals of Database Systems.

## Run locally

From the repository root, start the Vite frontend:

```sh
cd AutoParts
npm install
npm run dev
```

In a second terminal, start the Express API:

```sh
cd backend
npm install
npm run dev
```

The API loads `DATABASE_URL` from the root `.env.local` file generated by
`neon env pull` (or from the process environment in a deployed runtime). It
uses the pooled Neon connection for application queries. Check the API and its
database connection at `http://localhost:3001/api/health`.
